## Quick Start

```bash
npm run dev
# Visit http://localhost:3000
```

**Admin Access Flow:**
1. Sign up at `/sign-up`
2. Check `/auth/pending`
3. Admin assigns role in `/admin/accounts`
4. Login again
5. Access `/admin` dashboard
